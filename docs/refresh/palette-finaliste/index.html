Le tre finaliste sul timer

Il timer a tutto schermo è dove il colore lavora di più: ml giganti nel colore dell'acqua, caraffa che si riempie, accento che si accende negli ultimi 5 secondi di ogni step. Per ogni palette: estrazione in corso (V60, seconda versata), ultimi 5 secondi di uno step, riepilogo finale. Stessi font e stessa struttura dell'app.
